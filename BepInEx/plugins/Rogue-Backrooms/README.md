# The Backrooms

This mod adds the backrooms as a playable map to repo! Also feel free to check out [My Valuables Mod](https://thunderstore.io/c/repo/p/Rogue/Rogue_Valuables/)

## Note
- Everyone is required to install this mod.
- There are config options that increases the difficulty of the mod.
- Please report any bugs or glitches you find to the [Offical REPO Modding discord server.](https://discord.com/channels/1344557689979670578/1385029067006545932)
## Rooms

| Room Type         | Count |
|-------------------|:-----:|
| Start Rooms       |   6   |
| Normal Modules    |   7   |
| Passage Modules   |   2   |
| Dead-End Modules  |   3   |
| Extraction Module |   5   |
