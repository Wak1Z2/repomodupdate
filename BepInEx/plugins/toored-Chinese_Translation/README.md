### 📑配置文件
- 如果安装了REPOConfig，你可以打开模组-状态栏自动翻译配置，实时调节BUFF字体的大小以适应可能溢出屏幕的升级项(指超25个升级项目的重度MOD爱好者)

------------


### 💾安装方法

- 使用 Thunderstore Mod Manager 安装(推荐)

- 或者手动下载文件，解压BepInEx文件夹到游戏根目录里(例：SteamLibrary\steamapps\common\REPO)

- 不懂的直接点击看[教程](https://www.bilibili.com/video/BV1A8r9BoEtv "教程")
